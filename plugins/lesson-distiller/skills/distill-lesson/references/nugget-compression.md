# Intelligent learning compression

The source is inspected completely; the learner sheet is deliberately selective. The goal is lossy compression of source text and near-lossless compression of learning value.

For each candidate ask:

> If the learner remembers this after the lesson, will it materially improve their German?

Then choose one internal destination.

| Decision | Use when | Learner result |
|---|---|---|
| standalone | it deserves focused attention | its own vocabulary, grammar or Redemittel card |
| embedded | useful supporting language improves another selected example/pattern | visible naturally inside that item, no extra card |
| duplicate | the same meaning, form and communicative decision already has a home | one teaching home |
| excluded | it is source detail or noise with little learning payoff | absent from learner HTML |

## What normally earns a standalone home

- an explicit Wortfeld, Bildlexikon or targeted word bank;
- a complete small semantic set the lesson asks learners to notice;
- vocabulary necessary for the main situations or productive goal;
- recurring or useful level-appropriate collocations/constructions;
- every explicitly taught grammar concept and meaningful contrast;
- reusable speaking/writing frames, especially model-text language needed for the task.

An item may appear once and still be essential. Frequency never overrules explicit teaching value.

## What normally does not

- names, biographical facts, dates and one-off itinerary details;
- plot vocabulary needed only to understand one passage;
- routine instructions such as compare, tick or answer;
- ordinary support words that introduce no important sense, form or collocation;
- complete readings, transcripts, dialogues, letters and answer keys;
- variants differing only by a routine pronoun/conjugation change when one concise card can show both.

Do not exclude an item merely because it seems easy, appears once, or makes the count larger. Do not include it merely because it is a noun/verb/adjective in source text.

## Embedding without stuffing

An embedded item must occur naturally in the example, pattern or phrase recorded as its home. Good embedding strengthens retrieval:

- a vocabulary example reuses the lesson’s relevant case or connector;
- a Redemittel example includes a useful secondary topic word;
- a grammar example uses a key word from the explicit Wortfeld.

The embedded realization is visible and translated, but it is not highlighted as a competing primary target. Keep one clear retrieval target per example. Do not hide explicit grammar, essential vocabulary or a major writing template as “embedded.”

## Compression decisions

- Preserve a complete small taught set; do not arbitrarily keep five of seven workplace events.
- Merge exact repetition across a model text and a reference box.
- Combine formal/informal variants only when their function and structure match and the difference stays obvious.
- Keep `nicht brauchen` and `nur brauchen` distinct because they express different obligations.
- Keep `Genitiv` and genitive adjective endings separate when both are explicitly taught.
- Use a compact pattern rather than duplicating the same rule in prose, a table and a memory hook.
- Prefer one strong example over multiple weak examples.

There is no target card count. During review, justify both extremes: an essential omission and a card that adds no material learning value are both defects.
