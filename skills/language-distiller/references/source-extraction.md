# Complete source inspection

Build an internal map for the actual source revision; never infer lesson boundaries from a prior run.

## Inspect before selecting

For each lesson, verify:

- visible lesson badge, printed folio and zero-based PDF index;
- opener/outcomes;
- all lesson pages and picture vocabulary;
- margins and small grammar notes;
- grammar/communication reference pages;
- model texts, dialogues and productive writing/speaking tasks;
- linked partner or appendix activity when it adds learning content.

Text extraction is reconnaissance. Render and visually inspect regions where pictures, handwriting, tables, blanks or sidebars may be missing/corrupt. A page’s character count never proves review.

For a whole book, classify every page internally so shared module/reference material is not skipped. The map remains under `_work` or `_skill_test`, never in learner HTML.

## Sources other than a course book

The same inspection applies to any lesson material; only the unit of a "page" changes.

- **Lecture slides (PPT, PPTX, Google Slides):** export them to PDF, so every slide gets a stable index (`pdf_index` = slide number − 1). Read the speaker notes too. Teachers often put the explanation or the example sentences there, while the slide carries only a keyword.
- **Handouts and worksheets:** treat them like workbook pages. Fill-in tasks show which forms the teacher wants practised.
- **Typed or handwritten notes:** number the pages or sections and use them as indexes. Mark anything you cannot read as `unreadable`; do not guess.

A teacher's material is usually thinner than a book. Keep to the scope the lesson sets: the words, forms and uses it actually covers. When a slide only names a grammar point, still teach it fully and accurately on the sheet. Note internally which parts came from the material and which you supplied, so the review can check them.

## What inspection produces

Record potential learning candidates with exact source locations before deciding what deserves learner attention. Inspection should be broad; selection should be strict. Do not turn every token in a reading into a candidate card.

Capture:

- explicit vocabulary fields and complete small sets;
- recurring or goal-critical vocabulary/collocations;
- each explicitly taught grammar concept/contrast;
- reusable phrases from boxes, models and productive tasks;
- supporting words or constructions worth embedding;
- source-only narrative/details sufficient to justify exclusion.

For non-PDF notes/slides, use stable chunk/slide indexes. For PDF indexes, always pair zero-based index with visible folio.

## Media

Record referenced audio/video and whether supplied and inspected. Printed questions do not reveal spoken-only language or correct answers. Missing-media status stays in internal records and the delivery message, not the learner HTML. Do not fabricate listening coverage.

Temporary source renders belong in internal working folders. Preserve the supplied source and finalized learner artifacts.
